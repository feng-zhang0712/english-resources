### 编纂红线（摘要）

1. **配额不是任务**：[`章节配额.md`](编纂规范/章节配额.md) 中的数字是长期参考，**不得**为「凑满某章 N 词」而加词。
2. **质量优先**：只收日常与通用阅读中**真有用**的词；生僻、过专、拼缀垃圾、模板占位 —— **不写、不入表**。
3. **禁止脚本灌词**：不得批量生成词条或批量回填占位（历史 A39+ 终批已整批作废）。
4. **一词一条**：每个词只在**一个**中主题下有完整词条（见规范「主归属」表）。
5. **完成标准**：可教、可查的词条质量 —— **不是**词条行数是否接近配额。

扩写或审稿前，请先读 [`章节配额.md`](编纂规范/章节配额.md) 文首 **「给 Cursor / Agent 的硬性指令」**。
