## 给 Cursor / Agent 的硬性指令（优先阅读）

在编写、增补、扩写任何词条或 `_词表.md` 之前，**必须先读本节**。

### 禁止做的事

| 禁止 | 说明 |
|------|------|
| **按配额凑数** | 不得因「本章规模参考 720、目前只有 660」而批量加词。差额**不是**待办任务。 |
| **用脚本灌词** | 不得用脚本批量生成词条、批量改词表、终批/回填占位内容。见 [`README.md`](README.md)「禁止脚本」。 |
| **为派生而派生** | 不得机械收录 `-ness`、`-ity`、`-ousness` 等派生名物，除非该形式**本身**高频、易混、值得单独学。 |
| **跨章堆专名** | 不得把动物分类、化学元素、病理缀、诗律术语等塞进日常主题章（如情感、性格、行为）。 |
| **模板占位** | 不得写出「（见搭配）」式空释义、假音标、编造例句、大量「见下条」串联的 junk 词条。 |

### 收录前自问（任一条答「否」则不要写）

1. 受过普通高等教育的学习者，**未来两年**是否在通用阅读/口语中**很可能**遇到这个词？
2. 牛津学习词典、朗文、柯林斯等**主流学习词典**是否收录（非仅 OED 旧义或专科词典）？
3. 是否属于本章**中主题**（见下表「编纂说明」列），而非应归其他章？
4. 若删掉该词，本章是否**明显缺一块**常用表达？（若否，多半不必单独立条）

### 典型 junk 信号（见到即删词表行 / 勿新写词条）

- 词表垃圾、拼缀堆砌（如 `advantageousness`、`absinthine`、`actinocrinid`、`amphicoelous`）
- 仅史料/专科识读（古医学、植物属名、宗教专名、神话人物名作词条）
- 释义仅重复词性 +「见搭配」、例句明显模板化
- 用户**未明确要求**时，主动提出「还差 N 个词要补」——**不要**把规模参考差额当缺口汇报

### 完成标准（唯一）

**可教、可查、有真实 IPA、有真实例句**的词条数 —— **不以**接近表中「规模参考」数字为准。

## 编制说明

### 1. 规模参考 ≠ 写满

| 说明 | 要求 |
|------|------|
| **性质** | 「规模参考」列均为粗估，可上可下，**无义务对齐**。 |
| **修订依据** | 以第一章六卷正文（**2,823** 条，累计已删 junk **约 670** 条）反推：旧版单章预估普遍偏高约 **40%–55%**；动物/植物等被动专名章亦**不**按分类学全收。 |
| **实际可以更少** | 已发布词条数**低于**规模参考，属正常；**高于**亦须过质量门槛，禁止为凑数加词。 |
| **禁止凑数** | **绝不要**为接近表中数字而硬收生僻词、保留 junk、占位批量填词条。 |
| **优先级** | **可教性 > 主题契合 > 词表整洁**；**数字不参与优先级**。 |

### 2. 两列数字各表示什么

| 列名 | 含义 |
|------|------|
| **规模参考** | 质量筛词后的长期蓝图，**不是**本阶段必须达到的条数。 |
| **实际词条数** | 正文 `.md` 中已发布词条数，**仅作记录**；与规模参考的差额**不作**完成率。 |

### 3. 禁止脚本

执行本书相关任务时（写词条、改词表、清理 junk、统计、批量删行等）**一律不得用脚本批量处理内容**。须逐条人工判断。详见 [`README.md`](README.md)。
