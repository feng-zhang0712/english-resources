# 章节配额（规划参考）

> 本文件所列词数均为**预估数量**，用于分章、分工与长期规模设想，**不是**编写任务指标，**不是**验收 KPI，**不得**因「未达到表中数字」而补写不该出现的词。

## 编制说明（必读）

### 1. 预估数量 ≠ 必须写满

| 说明 | 要求 |
|------|------|
| **性质** | 下表「预估词数」「预估总词数」均为**粗估**，随筛词与质量审查可上可下，**无义务对齐**。 |
| **实际可以更少** | 某一章、某一中主题的词表行数或已发布词条数**长期低于**表中预估，属于正常、可取的结果。 |
| **禁止凑数** | **绝不要**为接近 6,200、1,500、1,200 等数字而：硬收生僻词、保留 junk 行、用占位模板批量填词条、把「完成率」当作目标。 |
| **优先级** | **可教性 > 主题契合 > 词表整洁**；**预估数量不参与优先级**。 |

全书约 35,000、13 个大主题各行的数字，与第一章「人与自我」6,200 及六个中主题细分，**同一标准**：仅作蓝图参考，详见 [README.md](../README.md) 第四节「编纂原则」。

### 2. 禁止脚本（任何任务均适用，极其重要）

**执行本书相关的任何任务时**——包括但不限于：编写/删改词条、维护 `_词表.md`、清理 junk、更新编纂进度、统计词数、批量删行、生成批次文件——**一律不得使用脚本**（Shell/Python/Node 等对多个文件或大量行做自动读写、生成、替换）。

- **必须**：人工阅读、人工判断、在编辑器中**手工**修改内容。  
- **禁止**：脚本批量生成词条；脚本批量改词表状态；脚本「终批/回填」；为凑预估行数而用工具链灌词。  
- **完成标准**：以**可教、可查、有真实 IPA** 的词条为准，**不以**是否达到本表预估词数为准。

生僻词一律不编、不入表：少见的、极其罕见的、一辈子基本用不到的、过专以致多数人接触不到的词——**直接删除词表行与词条**。详见 [README.md](../README.md) 第四节「禁止编写」。
