## Frank 的英文单词书

- **Goal**: Native-level vocabulary organized by **semantic themes**, not alphabet.
- **Entry modules**: definitions, examples, etymology, collocations, near-synonyms, etc. (see [`编纂规范/sample.md`](Frank%20的英文单词书/编纂规范/sample.md)).
- **Progress**: Volume **01-人与自我** (six sub-themes) has full body text; themes **00** and **02–12** have folder structure ready.

Details: [`Frank 的英文单词书/README.md`](Frank%20的英文单词书/README.md).

## Contributing (for collaborators)

1. Read [`编纂规范/README.md`](Frank%20的英文单词书/编纂规范/README.md) before editing entries.
2. **No batch scripts** on book content (no auto-generated entries, no bulk `_词表.md` updates).
3. One word, one full entry; quality over quota numbers.
4. Do not commit local automation under `scripts/` or `*_sort_entries.py` (see [`.gitignore`](.gitignore)).
