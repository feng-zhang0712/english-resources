## Frank 的英文单词书

- **Goal**: Native-level vocabulary organized by **semantic themes**, not alphabet.
- **Entry modules**: definitions, examples, etymology, collocations, near-synonyms, etc. (see [`编纂规范/sample.md`](Frank%20的英文单词书/编纂规范/sample.md)).
- **Progress**: Volume **01-人与自我** (six sub-themes) has **~3,140** published entries (quality-trimmed; chapter quota figures are **not** fill targets). Themes **00** and **02–12** have folder structure ready.

Details: [`Frank 的英文单词书/README.md`](Frank%20的英文单词书/README.md).

## Contributing (for collaborators and Cursor)

1. Read [`编纂规范/README.md`](Frank%20的英文单词书/编纂规范/README.md) and [`章节配额.md`](Frank%20的英文单词书/编纂规范/章节配额.md) (**「给 Cursor / Agent 的硬性指令」**) before editing.
2. **Quota numbers are not targets** — do not add words to hit chapter totals; teachability and everyday usefulness first.
3. **No batch scripts** on book content (no auto-generated entries, no bulk `_词表.md` updates, no filler/junk vocabulary).
4. One word, one full entry per theme; skip rare, overly specialized, or dictionary-only coinages.
5. Do not commit local automation under `scripts/` or sort/fix scripts (see [`.gitignore`](.gitignore)).
